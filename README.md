# Align Your Day

A simple local web page to start and finish your day with intention.

- Daily inspirational quote
- Five goals in five areas (Physical, Mental, Social, Emotional, Spiritual - inspired by Franklin Covey), with suggestions you can shuffle or edit
- Today's weather (Open-Meteo, no API key) with an outfit recommendation
- Water tracker (default 60 oz)
- "One thing I learned today" journal
- End-of-day review showing what you finished and what to carry over
- 7-day history, all saved in your browser (localStorage)

## Run
Open `index.html` in any web browser. Weather needs an internet connection; allow location for local weather (defaults to Meridian, ID).
